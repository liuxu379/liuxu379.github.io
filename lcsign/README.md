# LCSign 静态软件源

- 主页： https://hsbc.cc.cd/lcsign/
- LCSign 兼容格式软件源： https://hsbc.cc.cd/lcsign/appstore.json
- 完整目录： https://hsbc.cc.cd/lcsign/catalog.json
- 分卷源： sources/part-01.json 至 sources/part-14.json
- 源文件总数： 6348 条 IPA / TIPA 下载记录（IPA 6273、TIPA 75）

这个目录不会修改仓库原有博客页面或 CNAME。GitHub Pages 由已有 Jekyll workflow 发布；构建前会合并分卷 JSON。此仓库仅保存元数据和原始第三方链接，不托管安装包。

**注意：** 下载地址可能过期，未逐一核验可访问性、授权、签名和安全性。LCSign 客户端对该格式的兼容性需要在设备上确认。
